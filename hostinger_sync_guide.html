Step-by-Step Guide

MySQL → Hostinger
Full Table Replace Sync

Sync 20 selected tables from your local MySQL to Hostinger Managed Database

🔄
Key Difference from DigitalOcean

Hostinger uses standard port 3306 (not 25060). SSL is optional. Remote MySQL access must be manually enabled in hPanel → Databases → Remote MySQL. Your DB name and username are auto-prefixed with your account ID (e.g. u123456789_dbname).

01
Log in to hPanel and Create a Database
Set up your MySQL database on Hostinger

Go to hPanel → Hosting → Manage → Databases → MySQL Databases

ActionWhereNote
Create new DBMySQL Databases → CreateName gets auto-prefixed: u123456789_yourname
Create DB userMySQL Users → CreateUsername also gets prefixed: u123456789_user
Assign user to DBAdd User to DB sectionGive ALL PRIVILEGES
ℹ️ Note down the full auto-generated names — you'll need them exactly as shown (including the u123456789_ prefix) in the script config.
02
Enable Remote MySQL Access
This is the most important Hostinger-specific step

Go to hPanel → Databases → Remote MySQL and add your local IP:

# Step 1: Find your public IP
curl ifconfig.me

# Step 2: Go to hPanel → Databases → Remote MySQL
# Click "Add IP Address" and enter your IP
# Example: 103.45.67.89
# Click Add
⚠️ Without this step, you'll get a "Host not allowed to connect" error. If your home internet has a dynamic IP, you must update this each time your IP changes.
💡 On Hostinger VPS plans, remote MySQL may need to be enabled via phpMyAdmin → User Accounts → Edit Privileges as well.

04
Install Python Dependency
Install the MySQL connector on your local machine
# Install MySQL connector
pip install mysql-connector-python

# Verify it works
python3 -c "import mysql.connector; print('Ready ✓')"
05
Configure the Sync Script
Edit hostinger_sync.py with your actual credentials and table names
# ── LOCAL DB ──────────────────────────────────────────────
LOCAL_DB = {
    "host":     "localhost",
    "port":     3306,
    "user":     "root",
    "password": "YOUR_LOCAL_PASSWORD",    # ← change
    "database": "YOUR_LOCAL_DB",          # ← change
}

# ── HOSTINGER DB ──────────────────────────────────────────
HOSTINGER_DB = {
    "host":     "srv1234.hstgr.io",          # ← from hPanel
    "port":     3306,                          # standard port
    "user":     "u123456789_user",            # ← from hPanel
    "password": "YOUR_HOSTINGER_DB_PASS",    # ← change
    "database": "u123456789_mydb",           # ← from hPanel
}

# ── YOUR 20 TABLES ────────────────────────────────────────
TABLES_TO_SYNC = [
    "orders",    "users",     "products",
    "invoices",  "payments",  "customers",
    # ... all 20 table names here
]
06
Test the Connection
Verify both local and Hostinger connections before running sync
# Test local MySQL
mysql -u root -p -e "SELECT 'Local OK';"

# Test Hostinger connection
mysql -h srv1234.hstgr.io \
      -P 3306 \
      -u u123456789_user \
      -p \
      u123456789_mydb \
      -e "SELECT 'Hostinger OK';"
✅ Both should return a result. If Hostinger fails with "Host not allowed" → go back to Step 2 and whitelist your IP in Remote MySQL.
07
Run the Sync Script
Execute the full table replace — what happens per table
1
Auto-create table if missing

Copies CREATE TABLE structure from local → Hostinger if needed

2
Disable FK checks

SET FOREIGN_KEY_CHECKS = 0 to allow clean truncate

3
TRUNCATE the table

Wipes all existing rows on Hostinger for this table

4
Batch INSERT all rows

Fetches 1000 rows at a time from local, inserts into Hostinger

5
Re-enable FK checks

Restores integrity constraints after data is loaded

# Run the sync
python3 hostinger_sync.py

08
Verify via phpMyAdmin
Confirm data arrived correctly on Hostinger

Go to hPanel → Databases → phpMyAdmin and run:

-- Check row counts for your synced tables
SELECT TABLE_NAME, TABLE_ROWS
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = 'u123456789_mydb'
ORDER BY TABLE_NAME;
ℹ️ The script also writes a hostinger_sync_report.json file locally with full timing, row counts, and status per table — useful for audit logs.
09
Schedule Automatic Syncs
Automate with cron on Linux/Mac or Task Scheduler on Windows

Linux / Mac — cron:

crontab -e

# Every day at 3 AM
0 3 * * *   /usr/bin/python3 /path/to/hostinger_sync.py >> /var/log/hostinger_sync.log 2>&1

# Every 6 hours
0 */6 * * * /usr/bin/python3 /path/to/hostinger_sync.py >> /var/log/hostinger_sync.log 2>&1

Windows — Task Scheduler:

# Run in PowerShell to create scheduled task
schtasks /create /tn "HostingerSync" /tr "python C:\path\to\hostinger_sync.py" /sc daily /st 03:00

Troubleshooting Common Hostinger Errors
Quick fixes specific to Hostinger
Error MessageCauseFix
Host not allowed to connectIP not whitelistedhPanel → Remote MySQL → Add IP
Access denied for userWrong username/passwordCheck u123456789_ prefix in config
Unknown databaseWrong DB nameCopy exact name from hPanel DB list
Can't connect to serverWrong hostnameUse srv1234.hstgr.io from hPanel
Timeout / slow insertsLarge table / slow planLower BATCH_SIZE to 500
FK constraint errorRelated tablesScript handles this automatically
Max connections exceededShared hosting limitAdd time.sleep(1) between tables
💡 Hostinger shared plans have connection limits. If you hit them, add time.sleep(2) in the script after each table sync to pace the load.
